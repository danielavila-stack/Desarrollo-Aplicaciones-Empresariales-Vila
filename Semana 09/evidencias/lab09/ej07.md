# Ejercicio 7: citas médicas y recetas anidadas

La forma de los objetos corresponde a los campos del `CitaMedicaAnidadaSerializer` del Lab 08. Se usa `detalles` como nombre de la propiedad JSON anidada; cada detalle contiene `id`, `insumo`, `insumo_nombre`, `cantidad`, `indicaciones_uso` e `insumo_precio`. Los datos son estáticos, por lo que no se hace ninguna solicitud HTTP.

## Copia del renderizado anidado y cálculo

```jsx
{citasMedicas.map((cita) => {
  const costoTotal = cita.detalles.reduce(
    (total, detalle) =>
      total + Number(detalle.insumo_precio) * detalle.cantidad,
    0,
  )

  return (
    <article key={cita.id}>
      <h2>{cita.mascota_nombre}</h2>
      <p>Dueño: {cita.dueno_nombre}</p>
      <p>{cita.fecha_hora} · {cita.motivo} · {cita.estado}</p>
      <ul>
        {cita.detalles.map((detalle) => (
          <li key={detalle.id}>
            {detalle.insumo_nombre} × {detalle.cantidad}: {detalle.indicaciones_uso}
          </li>
        ))}
      </ul>
      <p>Costo total de insumos: S/ {costoTotal.toFixed(2)}</p>
    </article>
  )
})}
```

`reduce()` suma precio por cantidad para cada receta y obtiene el costo total de insumos de la cita.
