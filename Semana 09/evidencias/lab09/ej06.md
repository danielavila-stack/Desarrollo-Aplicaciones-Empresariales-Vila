# Ejercicio 6: condiciones en el inventario

Copia de la lógica condicional incorporada al listado:

```jsx
{insumos.length === 0 ? (
  <p>No hay insumos registrados</p>
) : (
  insumos.map((insumo) => {
    const stock = insumo.stock

    return (
      <article key={insumo.id}>
        <h2>{insumo.nombre}</h2>
        <p>{insumo.stock === 0 ? 'Agotado' : `Stock: ${insumo.stock}`}</p>
        {stock > 0 && stock <= 5 && (
          <span>⚠️ ¡Últimas unidades!</span>
        )}
      </article>
    )
  })
)}
```

El operador ternario presenta el estado del stock; el operador `&&` muestra la advertencia solo para cantidades entre 1 y 5. El condicional exterior informa cuando el arreglo está vacío.
