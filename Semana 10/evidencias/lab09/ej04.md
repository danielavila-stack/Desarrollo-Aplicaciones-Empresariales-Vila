# Ejercicio 4: JSX y expresiones dinámicas

Copia de `App.jsx` al completar el ejercicio:

```jsx
const clinica = 'Veterinaria Pet Care'

function App() {
  return (
    <>
      <h1>🐾 Veterinaria Pet Care - Panel de Control 🐾</h1>
      <p>Bienvenidos a {clinica}.</p>
      <p>El precio del servicio con IGV es S/ {(50 * 1.18).toFixed(2)}.</p>
    </>
  )
}

export default App
```

Las expresiones entre llaves insertan el valor de `clinica` y el resultado del cálculo con IGV en el JSX.
