# Sistema de Gestión Veterinaria - PetCare

Sistema web para la administración y control de un centro veterinario, desarrollado con el framework **Django** bajo el patrón **MVT (Model-View-Template)** y base de datos **SQLite**.

## Características y Requisitos Funcionales

* **Gestión de Especies:** Registro y eliminación de especies atendidas.
* **Inventario de Insumos:** Registro, actualización de stock y control de precios.
* **Control de Servicios:** Mantenimiento de precios y lista de servicios médicos ofrecidos.
* **Gestión de Mascotas:** Registro, edición, eliminación y consulta de pacientes y sus responsables.
* **Historial Médico:** Registro de consultas vinculadas a cada mascota (`ForeignKey`), almacenando diagnóstico, tratamiento y fecha.
* **Búsqueda Avanzada:** Filtro de mascotas por nombre o por nombre del dueño en tiempo real.

---

## Tecnologías Utilizadas

* **Lenguaje:** Python
* **Framework:** Django
* **Base de Datos:** SQLite
* **Frontend:** HTML5, Bootstrap
* **Control de Versiones:** Git & GitHub
